# 05. The Ubiquitous Visual Engine

> **Fully superseded by [00-FRAMEWORK](00-FRAMEWORK.md).** This document
> specified the no-code Builder — a drag-and-drop canvas summoned anywhere
> data needed presenting (storefront, invoice, gallery, proposal), with every
> block bound to live data. It was built, used, and removed — it felt like a
> dataview, not a studio's own tool. There is no visual engine, no canvas, no
> block library, and no data-binding layer in the current system. Public
> surfaces (the booking page, client galleries) are hardcoded pages, same as
> the dashboard.
>
> Kept only so the decision has a paper trail. Do not build against anything
> below this line.
